# Repository Setup

This repository is designed to be the GitHub profile repository for:

## Publish

1. Create a **public** repository named exactly `Zanuu-mughal-1`.
2. Upload the contents of this folder to the repository root.
3. Keep `README.md` in the root.
4. Replace the placeholder SVG identity marks in `assets/` with official high-resolution logos if desired.
5. Update the LinkedIn URL in `README.md` to the actual profile URL.

## Important

GitHub automatically renders the README of a public repository whose name exactly matches the GitHub username.
